  `vendor-dnd`, `vendor-icons`, `vendor-state`, and a catch-all `vendor`.

- Every feature page (coach + athlete + auth + landing) is now lazy-imported.
- Added a typed `lazyNamed(loader, name)` helper so named exports (which every
  feature module in this repo uses) work with `React.lazy`'s default-export
  contract without adding default-export shims to each page file.
- Layouts (`CoachLayout`, `AthleteLayout`) stay eager so the sidebar/top-nav
  paints immediately while the active page chunk streams in.
- Each route element is wrapped in `<Suspense fallback={<RouteFallback />}>`.

- Lightweight synth-themed loader: light canvas, pulsing emerald dot, mono
  `loading` label. Reads only `THEME.*` tokens (no hardcoded colors/fonts).
